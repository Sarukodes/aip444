# Assignment 1: AI Code Review

This project is a CLI-based AI code review tool for AIP444 Assignment 1.

## Features

- File Mode using `--file`
- Git Mode using staged git changes
- Debug Mode using `--debug`
- Two parallel AI reviewers
- Tool calling with `read_file` and `ripgrep`
- Final HTML report generation by a Lead Developer judge

## Implemented Reviewers

1. Security Auditor
2. Maintainability Critic
